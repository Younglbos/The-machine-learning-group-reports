# 实验06 课程统一协议比较

本目录是课程主实验。实验04、05保留原作者复现协议；本目录另外统一数据、缺失定义、视图顺序和评价条件，不将不同协议下的数值直接比较。

**主实验A/B已实际完成并核验。** A含81条缺失质量记录及9条完整参考；B含144条批次记录。配对掩码/输入哈希均已核对，B的90秒预算未超限。统计表与图在根目录 `reports/`，消融、噪声与隔离效率另见已完成的实验07。完整报告与文献说明也位于 `reports/`，252条课程预测可由公开标签档案重新核验。

## 文件

| 文件或目录 | 用途 |
| --- | --- |
| `config_a.json` | 冻结的场景A矩阵：3模式、3比例、3种子 |
| `config_b.json` | 冻结的场景B协议、90秒预算和课程适配参数 |
| `run.py` | 独立运行A、B，或顺序执行全部后续实验 |
| `results_a/baselines/` | 同一Conda环境重新运行的零/均值填充和完整参考 |
| `results_a/hsacc/` | 已观测数据标准化、固定500轮的HSACC课程结果 |

```powershell
python scripts/run_in_environment.py experiments/06_course_comparison/run.py --stage a
```

`--stage all` 会继续调用实验07的冻结消融、鲁棒性和独立效率测量。长实验可重启；HSACC只有在配置与输出完整时才复用结果，B按完整方法/种子/条件复用已完成病例。

## 场景A

Caltech101-20，2386个样本、20类，HOG 1984维和GIST 512维。缺失率指不完整样本比例，每个被选择样本丢失一个完整视图；20%、40%、60%对应约10%、20%、30%的视图块缺失。

随机、单视图集中和类别相关缺失各运行3个比例与种子1、2、3。所有方法调用同一个掩码函数并保存SHA-256。逐特征MinMax只在已观测样本上拟合。HSACC使用作者网络、损失和固定500轮规则；最终聚类与填充基线均使用相同K、种子和10次K-means初始化。完整数据参考单列，不能当作同一缺失条件下的部署方法。

## 场景B

HandWritten，2000个对象、10类，6个视图按来源顺序到达，维度为240/76/216/47/64/6。种子11、21、22；第3批开始对新到达视图加入一个特征标准差的高斯噪声，并与无漂移条件成对比较。所有方法保存当前原始输入的相同SHA-256。

每个当前视图单独归一化，使用同一对象顺序。warm-start和滑动窗口使用16维PCA、补零到固定维度、无标签正交对齐；预处理维护一个N×16的历史共识摘要。warm-start保留中心，滑动窗口另保留最近2批低维表示。全量重训练作为参考，保留已经到达的全部标准化视图。

**DSVC课程适配与原作者运行分开：**复用作者自动编码器、注意力和损失函数，按固定对象组对应原型缓冲；推断时使用已学习的注意力并切换到eval模式。当前表示与历史共识作无标签正交对齐，以0.5指数遗忘更新一个N×256摘要；以旧簇中心初始化当前共识聚类。仅原型缓冲、共识和中心进入下一批，不重读过去的原始视图。

相对作者入口，这改变了全局推断注意力、批次原型对应方式和历史融合规则，因此命名为 `dsvc_course`，不冒充原论文的逐行复现。

每批时间预算在运行前固定为90秒，依据此前作者代码试运行约50秒的首视图耗时作硬件校准。超过预算则记录失败，不事后更改阈值。各方法/种子/条件使用独立进程，记录原生进程峰值、GPU分配峰值和保留状态；进程峰值包含该方法的解释器与依赖。

历史探针为首视图的96个固定对象表示，仅由评估器保存，不参与更新。全量参考的旧探针为首视图特征加零填充未来维度；其他方法在固定对齐空间查询旧表示。该指标评价旧表示查询的保留，不能等同于跨空间完全一致的遗忘机制。同时报告当前聚类、标签匹配后变化和漂移恢复，避免只看稳定性。
