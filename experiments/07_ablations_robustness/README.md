# 实验07 消融 鲁棒性与效率

运行顺序由实验06完成标记控制。所有设置在配置文件中冻结，不根据结果选择最好种子。

```powershell
python scripts/run_in_environment.py experiments/07_ablations_robustness/run.py
```

依赖实验06A已完成；入口先完成或复用06B，再运行本实验。首次使用建议通过实验06的 `--stage all` 顺序运行。

| 目录或文件 | 设置与用途 |
| --- | --- |
| `results/no_consistency/` | 一致性及分布对齐损失系数设为0 |
| `results/no_completion/` | 推断损失系数设为0，缺失表示不补全 |
| `results/equal_weights/` | 用常数等权替换视图权重函数 |
| `results/noise_hsacc/` | 第一个视图在已观测行加入1个标准差高斯噪声 |
| `results/noise_baselines/` | 使用完全相同噪声与掩码的零/均值填充 |
| `results/isolated_efficiency.csv` | 代表性条件下各方法独立进程计时和内存 |

统一条件为Caltech101-20 HOG/GIST、不完整样本比例40%、随机缺失、固定500轮、种子1、2、3。完整方法与无噪声控制来自06A的相同条件，不混入原作者协议的指标。

噪声尺度只从该视图的已观测行估计。完整隐藏特征仅用于训练后的诊断。消融关闭对应损失，不一定移除其前向计算，因此消融耗时不用于声称模块的计算加速。

双视图HSACC的权重函数关于两视图均值对称，理论上会退化成等权。等权消融的结果必须结合这一结构解释，不能仅凭浮点训练差异宣称自适应权重有效。

独立效率试验使用同一40%随机缺失条件，每个方法、种子启动全新进程，结果不作为新增随机种子加入质量表。进程原生峰值包含依赖库、原始数据与初始化；GPU峰值另列。HSACC时间包含作者周期评估，不能把它解释为已剔除评测开销的纯训练时间。
